# ShopSense — B2B 定位一页纸

**一句话**:给电商的"可信、可感知"商品详情页内容引擎——自动生成读屏可用的富商品描述与评论综合,帮零售商满足 EAA 无障碍合规、同时提升 SEO 与转化。

---

### 问题
EAA 自 2025-06-28 在欧盟 27 国生效,电商商品页必须达 WCAG 2.1 AA,单次违规最高罚 10 万欧元。但大多数零售商有几千到几万 SKU,商品图缺乏有意义的文字替代、评论难以被读屏用户消化。手写不现实,买 overlay 又被 FTC 罚、照样被诉。

### 为什么是现在(Why now)
法规已生效、罚款在执行、过渡期 2030 截止——**强制需求已打开,无需教育市场**。同时 overlay 方案信誉崩塌(accessiBe 被 FTC 罚 100 万美元),市场正在寻找"真正修复内容"的替代品。

### 产品(一个引擎,四个价值主张)
1. **合规**(why now):为商品图生成 WCAG 级文字替代 + 读屏友好的评论摘要,附**合规审计报告**(改前/改后、覆盖率)。
2. **SEO**(why pay):结构化富描述 + alt 文本提升搜索可见性。
3. **转化**(why pay):评论综合结论 + PDP 内问答,降跳出、提加购。
4. **省成本**(why pay):替代人工撰写商品文案/alt,规模化降本。

> 合规是进门理由,SEO/转化/降本是续费理由。

### 目标客户(ICP — 先聚焦一个)
有欧洲消费者、SKU 数千到数万、**没有专职无障碍团队**的中型电商(优先 Shopify / 时尚与家居类目)。买单人:合规/法务 + 电商运营负责人。

### 差异化(为什么不是"又一个工具")
- **对立于 overlay**:不是注入 JS 遮盖,而是真正生成可用内容——直接回应被 FTC 罚的痛点。
- **超越 alt 文本红海**:不止单图短 alt,而是**多源综合(图+评论+知识)+ 内容可信度 QA(文案与评论矛盾预警)+ 读屏对话式问答**——现有 alt 工具都不做。
- 可信度 QA 既是差异化,也是 B 端入场券(防 AI 幻觉给商户带来法律/退货风险)。

### 商业模式(假设,待验证)
Shopify App 自助安装 → 按 SKU/月订阅;合规审计报告作免费引流。先 PLG 跑通中小商户,再向中型零售商做含审计背书的年签。

### 90 天验证计划(代码之前先做)
1. **客访 5 家** ICP 商户的合规/电商负责人:是否知道 EAA?现在 alt 怎么处理?愿为自动化+合规报告付多少?
2. **造一个 demo**:喂任意商品页 URL → 输出合规审计报告 + 富描述 + 评论摘要样例。用它换访谈。
3. **可付费意向**:拿到 ≥3 家"愿意试用/预付"信号再写产品代码。验证不过即止损。

### 主要风险
- 护城河薄(AI 商品化)→ 壁垒靠合规可追溯 + 集成深度 + 信任,而非算法。
- 合规承诺红线:只能写"协助达成/降低风险",**绝不保证全合规**(FTC 先例)。
- 平台/红海玩家向上扩展 → 必须守住"体验层 + 审计"高地。
